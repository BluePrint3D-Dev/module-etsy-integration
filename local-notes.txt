1. Advanced Inventory & Order Syncing

* Two-Way Stock Sync: Freemium syncs stock from Magento to Etsy. Pro syncs stock back from Etsy to Magento when an Etsy sale happens (preventing accidental overselling across channels).
* Etsy Order Import: Automatically pull Etsy orders straight into Magento's order management grid as native Magento orders, keeping fulfillment all in one dashboard.
* Tracking Number Push: Automatically push shipment updates and tracking carrier info back to Etsy as soon as the Magento shipment is generated.

2. Multi-Store & Custom Mapping Logic
* Multi-Store View Mapping: Map specific Magento Store Views to different Etsy shops (ideal for merchants running international shops or distinct brands from one Magento backend).
* Dynamic Price Rules: Allow merchants to apply price modifiers specifically for Etsy (e.g., "Automatically markup all Etsy prices by +15% or +£2 to cover Etsy transaction fees").
* Automated Category Mapping Rules: Auto-map Etsy Taxonomy IDs based on Magento product attributes (like SKU patterns, brand, or custom attributes) rather than manual category assignment.

3. Configurable Products & Variant Variations
* Configurable / Matrix Sync: Handle true Magento Configurable Products (Child SKUs with size/color/material matrix variations) to map natively to Etsy's Red Box variations.
* Custom Option Price Surcharges: Compute and reflect option price modifiers (e.g., +£5 for Engraving) on Etsy's listing variations seamlessly.

4. Admin Diagnostics & Bulk Controls
* Mass Action Bulk Queueing: Add a "Sync to Etsy" option to the native Magento Product Mass Action dropdown for 1-click bulk updates.
* Sync Health & Error UI Dashboard: A dedicated grid in the Magento Admin showing failed sync items, complete error logs from Etsy's API, and a 1-click "Retry Sync" button.
* Automated Webhooks: Instant real-time updates using Magento product update events rather than waiting for cron intervals.
