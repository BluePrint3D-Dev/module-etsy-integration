Etsy Integration

Install and configuration guide. Syncs your Magento catalogue to Etsy using the API v3, with a background queue so product saves in admin stay instant.

Package blueprint3d/module-etsy-integration
Module BluePrint3D_EtsyIntegration

1

What it does

Most Etsy connectors make slow, synchronous API calls during product save, which can lock up the admin edit page. This module instead queues each change into a database table (blueprint3d_etsy_queue) and syncs it in the background via cron, so saving a product in admin stays instant.

Built for Etsy API v3, it converts both native Magento Custom Options and BluePrint3D Shared Product Options into Etsy Personalizations and dropdowns automatically.

Installation

  1. 1
    Install via Composer
    $ composer require blueprint3d/module-etsy-integration
  2. 2
    Enable the module
    $ php bin/magento module:enable BluePrint3D_EtsyIntegration
  3. 3
    Run setup upgrade
    $ php bin/magento setup:upgrade
  4. 4
    Compile and flush cache
    $ php bin/magento setup:di:compile
$ php bin/magento cache:flush

4

First sync

  1. Connect your Etsy shop

    Enter your App Key and Shared Secret, then complete OAuth authorization.

  2. Sync the category taxonomy

    Downloads Etsy's categories so you can map your own against them.

  3. Map categories

    Under Catalog > Categories, assign an Etsy Taxonomy ID to each category you plan to list.

  4. Choose your sync mode and options handling

    Pick real-time or cron, and strict or lenient handling for unsupported options.

  5. Save a product to queue it

    Saving any mapped product queues it for sync - immediately in real-time mode, or on the next cron run otherwise.
